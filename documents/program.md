# プログラムの方法

## 共通ルール

- プログラムはスニペットという単位で行い、どのスニペットを使用するかを設定することで制御する。
  - スニペットは、スニペット設定単位ごとに複数のスニペットを選んでリストとしてセットできる。セットする時には前提条件を付与できる。
    - 前提条件には、グローバル変数を用いた条件文を指定できる
  - スニペットリストの上から順に、前提条件が満たされているスニペットが実行される
    - スニペットが無効なアクションを設定しようとした場合（例えば、無効なプラグインで定義されたアクション等）、単にその処理のみが無視される（エラーでの停止はせず、後続処理は実行される）
    - スニペットによる設定は、後続のスニペットによって上書きされる可能性がある
  - スニペットは引数をもてる
    - スニペットは自分でつくる他にできあいのものを使用することもできる。
      - できあいのものを使用場合でも、引数の与え方と「〇〇なら」（前提条件）の工夫によって、よりよい戦略を建てられる。
- 変数の種類
    - ローカル変数
      - 各スニペットの中でのみ読み書きが可能。スコープはそのスニペット内に閉じ他に影響しない。
    - グローバル変数
      - スニペットから変更可能な他、UIからも変更が可能（大局的な戦略についてプレイヤーが介入できる）
      - スニペットの引数として渡すことができる
      - 前提条件の中で参照が可能
    - プラグインのOn/Off状態
      - 読み取りのみ可
      - スニペットの引数として渡すことができる

下記のプログラムが可能

|プログラム種類|対象|スニペット設定単位|
|--|--|--|
|国家アクション（外交）|他国|-|
|国家アクション（スパイ）|他国|-|
|国家アクション（交易）|資源・特産品|-|
|国家アクション（軍規）|自国|-|

## ユニットアクションのプログラム

- スニペットリストの最後まで終わってもどのスニペットからもアクションが指定されない場合、ユニットは「防衛」アクションを実行予定とする

- スニペットの処理「××する」内でできることには下記がある
    - ユニットに「タグ」を設定する
    - ユニットに「目標地点」を設定する
    - ユニットの「アクション」を決定する
    - グローバル変数に値を設定する

### 重要な点
- ユニット毎に設定できる目標地点はターンをまたいで保持される。
    - 目標地点は、国家アクションで決めた目標候補から選んでもいいし、ユニットごとに個別に選んでもよい
- ユニット毎に設定できるアクションは、ターンをまたいで保持されない（毎回設定する必要がある）

### 使える関数

- calc_turn(ユニット,スタート地点,ゴール座標)
  - ユニットがスタート地点からゴール地点に到達するまでに必要なターン数
  - 他国軍事ユニットによる妨害は考慮せず進めるものとするが、他国拠点施設への進入不可条件は考慮する
  - ルートは視覚確認済み領域のみを使って計算される（未確認領域は使用されない）
  - ルートが存在しない場合は、+infを返す
- calc_real_turn(ユニット,スタート地点,ゴール座標)
  - calc_turnにおいて他国軍事ユニットによる妨害を考慮する版
    - 民間ユニットは他国（戦争中）軍事ユニットのマスを通過できない
    - 軍事ユニットは他国（平和中）軍事ユニットのマスを通過できない
      - 戦争中の他国軍事ユニットは通過可能（殴って通過）とみなすが、撃破に必要なターン数は考えない
  
### 例
- スニペット例１：　一般手配
    ```
    引数：対象ユニットタイプ
    引数：目標人口
    引数：使用タグ

    手配済ユニットリスト = 「自国アクション未定ユニットリスト」の内、{使用タグ}タグがついており「目標地点」が設定されている
    for ユニット in 手配済ユニットリスト:
      ★ユニットに「移動」アクションを設定

    目標候補リスト = 目標候補リストのうち、目標候補に{使用タグ}タグがついているもの
    for 目標候補 in 目標候補リスト:
      手配済人口 = 目標候補を目標地点とし{使用タグ}タグがついているユニットタイプが{対象ユニットタイプ}の人口の合計
      if 手配済人口 < {目標人口}:
        手配候補ユニットリスト = 「自国アクション未定ユニットリスト」の内、条件（ユニットにタグがついていない or {使用タグ}タグがついており「目標地点」が設定されていない or {使用タグ}タグがついており「目標地点」が「目標候補」に含まれない、ユニットタイプが{対象ユニットタイプ}である）を満たす
        for ユニット in 手配候補ユニットリスト.sort(x:calc_turn(x,x.位置,目標候補)):
          不足人口 = {目標人口}-手配済人口
          if 不足人口<=0:
            break
          if 不足人口 < ユニットの人口:
            success = ★ユニットに「分隊」アクション（指示値として、「人口」に不足人口、「移動目標」に目標候補、タグとして{使用タグ}）を設定
            if success:
              手配済人口+=不足人口
          else:
            if ユニット.位置==目標候補:
              手配済人口+=ユニット人口
            else:
              success = ★ユニットに「移動目標」に目標候補を指定、{使用タグ}タグを指定、「移動」アクションを設定
              if success:
                手配済人口+=ユニット人口
    ```

- スニペット例２：　均等防衛
    ```
    引数：{対象ユニットタイプ}：陸上軍事ユニット
    引数：{防衛に割く割合}：float
    引数：使用タグ=「防衛」

    防衛目標候補リスト = 目標候補リストのうち、目標候補に{使用タグ}タグがついているもの
    同一ユニットタイプリスト　＝　「自国ユニットリスト」の内、ユニットタイプが{対象ユニットタイプ}であるもの
    各防衛目標防衛人口 = 同一ユニットタイプリストの総人口に{防衛に割く割合}を掛けた値を「防衛目標候補リスト」の要素数で割った値
    ◆スニペット（一般手配）をコール：対象ユニットタイプ={対象ユニットタイプ},目標人口=各防衛目標防衛人口,使用タグ={使用タグ}
    ```
- スニペット例３：　新規拠点作成
    ```
    引数：{対象ユニットタイプ}：定住アクションが可能なユニット（例：開拓者）
    引数：目標人口：int(>=1)
    引数：使用タグ=「拠点作成」

    ◆スニペット（一般手配）をコール：対象ユニットタイプ={対象ユニットタイプ},目標人口={目標人口},使用タグ={使用タグ}

    for ユニット in 「自国アクション未定ユニットリスト」の内、ユニットタイプが{対象ユニットタイプ}で、{使用タグ}タグがついていて、ユニット.移動目標＝＝ユニット.位置:
      if get_base(ユニット.位置) is None:
        ★ユニットに「定住」アクションを設定
      else:
        ★ユニットに「編入」アクションを設定

    ```
- スニペット例４：　伐採による空地確保
    ```
    引数：{施設タイプ}:施設タイプ

    for ユニット in 「自国アクション未定ユニットリスト」の内、ユニットタイプが「開拓者」で、「伐採」タグがついていて、ユニット.移動目標＝＝ユニット.位置:
      if get_facility(ユニット.位置).タイプ==伐採場:
        ユニットの伐採タグをはずす
      else:
        ★ユニットに「建造」アクションを設定

    for 拠点 in 自国拠点リスト:
      if 拠点において{施設タイプ}が建造可能なマス数==0:
        if 拠点の接続マスリストの内、{施設タイプ}の対象地形であり伐採場があるマスの数==0:
          建造候補地点リスト = 拠点の接続マスリストの内、{施設タイプ}の対象地形かつ森林>0であるマス
          for 建造候補地点 in 建造候補地点リスト.sort(x: 建造にかかるターン数+森林0になるまでのターン数)
            候補ユニットリスト = 「自国アクション未定ユニットリスト」の内、ユニットタイプが「開拓者」で、「伐採」タグがついていないユニットの中で、建造候補地点に到達可能
            if len(候補ユニットリスト)>0:
              ★候補ユニットリスト.sort(x: calc_turn(x,x.位置,建造候補地点))[0]のユニットの「移動目標」に建造候補地点を指定、「伐採」タグを指定、「移動」アクションを設定
    ```
- スニペット例５：　帰還
    ```
    for ユニット in 「自国アクション未定ユニットリスト」:
      if get_base(ユニット.位置) is not None:
        ★ユニットに「編入」アクションを設定
      else:
        ★ユニットに「移動目標」に自国拠点リスト.sort(x: calc_turn(x,ユニット.位置,x.位置))[0]を指定、「移動」アクションを設定
    ```

## 拠点アクションのプログラム

### 例
- スニペット例１：　伐採の為の開拓者生成(技術0以上用)
    ```
    引数：{施設タイプ}:施設タイプ
    引数：{施設数}：int
    引数：{１施設あたりの建造ターン数}：int

    for 拠点 in 自国アクション未決定拠点リスト:
      if 拠点に接続している{施設タイプ}の数 < {施設数}:
        if 拠点から３マス以内にいる自国開拓者の数==0:
          if 拠点において{施設タイプ}が建造可能なマス数==0:
            if 拠点の接続マスリストの内、{施設タイプ}の対象地形であり伐採場があるマスの数==0:
            　希望人口=<施設タイプ>.必要労力/{１施設あたりの建造ターン数}
              
              ★拠点に「募集（開拓者,人口=希望人口）」を設定
    ```
