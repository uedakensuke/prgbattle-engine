# 戦闘

## 基本概念

- 国同士には交戦状態と平和状態がある
- 各マスにはユニットがスタックしうる
  - 軍事ユニットはある１国のみが存在する
  - 民間ユニットは複数の国のユニットが存在しうる
- 交戦状態にある他国の軍事ユニット・民間ユニットがいるマスに自国軍事ユニットが入ろうとした場合は戦闘となりうる。下記パターンの通り
  - ある国から見たときに、あるマスの状態は下記の４分類
    - パターン１：軍事ユニットがいない
    - パターン２：自国の軍事ユニットがいる
    - パターン３：他国（平和）の軍事ユニットがいる
    - パターン４：他国（交戦）の軍事ユニットがいる

|パターン|自国軍事ユニット|他国（交戦）軍事ユニット|他国（平和）軍事ユニット|自国民間ユニット|他国（交戦）民間ユニット|他国（平和）民間ユニット|攻撃可否|非交戦国巻き添え|
|--|--|--|--|--|--|--|--|--|
|1a|×|×|×|〇|不問|不問|×(自国民保護)|-|
|1b|×|×|×|×|〇|〇|△(軍規による)|〇|
|1c|×|×|×|×|〇|×|△(軍規による)|×|
|1d|×|×|×|×|×|〇|〇:交戦国拠点（城壁強度>0）|〇|
|1e|×|×|×|×|×|×|〇:交戦国拠点（城壁強度>0）|×|
|2|〇|×|×|不問|-|不問|×(対象不在)|-|
|3a|×|〇|×|-|不問|〇|〇|〇|
|3b|×|〇|×|-|不問|×|〇|×|
|4|×|×|〇|不問|不問|不問|×(交戦不可)|-|

- 巻き添えの可能性
  - 攻撃対象マスに他国（平和状態）の民間ユニットがいて、戦闘に巻き添えになる可能性がある
- 保護の可能性
  - 他国（交戦状態）の民間ユニットが他国（平和状態）の軍事ユニットと同じマスにいる場合、攻撃対象にできない

## 戦闘結果を左右する要素
- 戦力倍率
  - 資源ボーナスによって向上する。
- 忠誠補正(-1～1)
  - 忠誠補正 = (攻撃ユニットの自国への忠誠心-攻撃ユニットの防御側の国への忠誠心)/200
- 地形防御ボーナス
  - 最大ボーナス：山(1.0)+森林（0.5）+防衛陣地（0.5）=2.0
- 防御態勢
  - 拠点・施設内にいるユニットで本ターンに攻撃・移動していないユニットに適用される
- 側面攻撃ボーナス
  - 攻撃側は防御態勢でないユニットを正面以外から攻撃している場合、側面攻撃ボーナスを得る
    - 60度：0.2
    - 120度：0.8
    - 180度：1.0
  - 防御態勢のユニットを攻撃している場合、側面攻撃ボーナスは得られない
- 同時突撃ボーナス　※狙撃では発生しない
  - 防御側を同時に突撃しているユニット数(1~12の値)の倍率ボーナス
  - 「陸上ユニットからの攻撃」では最大１８ユニットから同時に突撃されうる。６地点×３ユニットタイプ（戦車・騎兵・歩兵）
  - 「水上ユニットからの攻撃」では最大６ユニットから同時に突撃されうる。６地点×１ユニットタイプ（軍船）
- 包囲ボーナス
  - 防御側を同時に攻撃している方向数(1~6の値)の倍率ボーナス
- 城壁強度
  - 防御側が城壁強度が0でない拠点上にいる場合、防御側の人口損失が減り攻撃側の人口損失が増える
- 防御側被ダメ率
  - (1+忠誠補正)*(1+側面攻撃ボーナス) / (1+城壁強度) * 包囲ボーナス / (1+地形防御ボーナス)
- 攻撃側被ダメ率
  - (1-側面攻撃ボーナス) * (1+城壁強度) / 同時突撃ボーナス

## 戦闘順序
- 戦闘は次の順序で行う
  1. 戦場マスの決定
  2. スタック合流処理
  3. 狙撃（と防御）
    - ダメージ計算
    - 水上ユニットの人口減少による定員オーバー処理
  4. 軍事水上ユニットからの突撃（と防御）
    - ダメージ計算
    - 水上ユニットの人口減少による定員オーバー処理
  5. 軍事陸上ユニットからの突撃（と防御）
    - ダメージ計算

### 戦場マス／混戦マスの決定
- 戦場とはこのターンに「狙撃」もしくは「突撃」されているマス、および「突撃」しているユニットがいるマスを指す
- 混戦マスとは、前ターンに「突撃」されているマスを指す
  - 混戦マスにいるユニットは狙撃を行えない
- 突撃とは
  - 「移動」アクションの目標位置に敵ユニットがいる場合でそのマスへの移動ポイントが進入ポイント以上となった場合、軍事ユニットでは突撃が発生する。この目標位置は当該ユニットが進入可能な地形である必要があるが、乗船中の陸上ユニットが船と共に水上ユニットに突撃する場合に限り、通常進入不可な海/湖であってもOKとする

### スタック合流処理
- 戦場マスでは、「同じユニットタイプ」かつ「乗船状態が同じ」複数のユニットを強制的に合流する
  - この時、最も人口が多いユニットがベースになる

### ダメージ計算
- 戦闘の計算は、「狙撃」、「軍事水上ユニットからの突撃」、「軍事陸上ユニットからの突撃」の３段階でそれぞれ分けて計算する。
  - それぞれの段階で下記の順序で計算する
    - 城壁への攻撃
    - ユニットへの攻撃（城壁強度が残っている場合でもユニットは攻撃を受ける）
  - それぞれの段階で0.01を下回ったユニットは消滅する
- 戦闘の計算は、防御側ユニットごとに行う
  - 防御側ユニットがいるマスに複数のユニットがいる場合、「攻撃側の人口」を防御側ユニットの人口比で案分して使用する

||狙撃|突撃|
|--|--|--|
|攻撃側の人口損失|なし|0.1 × 攻撃側被ダメ率 × 防御側の人口 × 防御側の戦力倍率 / 攻撃側の戦力倍率|
|防御側の城壁強度損失|Σ(攻撃側の人口 × 攻撃側の戦力倍率)/防御側の戦力倍率/城壁規模 × 狙撃攻城倍率|Σ(攻撃側の人口 × 攻撃側の戦力倍率)/防御側の戦力倍率/城壁規模|
|防御側の人口損失|0.05 × 防御側被ダメ率 × Σ(攻撃側の人口 × 攻撃側の戦力倍率) / 防御側の戦力倍率 |0.1 × 防御側被ダメ率 * Σ(攻撃側の人口 × 攻撃側の戦力倍率) / 防御側の戦力倍率 |
|攻撃側の物資損失|攻撃側の人口|攻撃側の人口 × 0.1|
|防御側の物資損失|攻撃側の人口 × 0.1|攻撃側の人口 × 0.1|

- 「城壁への攻撃」における「防御側の人口」「防御側の戦力倍率」はユニットの中で最も戦力倍率が高いユニットの値を用いる（ユニットがいない場合は1）
- ※Σは全攻撃ユニット
- 狙撃攻城倍率
  - 火薬がない場合0.1
  - 火薬がある場合は0.3
  - 火薬と鋼鉄がある場合は1

### 定員オーバー処理
- 乗船中の全陸上ユニットを同じ割合で定員になるまで減損

## デザイン
- 攻城
  - 例：城壁規模の1/10の戦力倍率10の歩兵で戦力倍率10の歩兵がいる拠点を攻撃した場合、1ターンで城壁は0.1減る（攻撃側の損耗がない場合は、10ターンでなくなる）
  - 例：城壁規模の1/10の人口の戦力倍率10の歩兵で攻撃した場合、1ターンで城壁はなくなる
- 突撃攻撃の場合
  - 例えば、攻撃側の総人口が防御側の人口のr倍(攻撃側がNユニットいる場合で、各攻撃ユニットの人口は防御側の人口のr/N倍)
    - 攻撃側の人口損失割合＝0.1 * 攻撃側被ダメ率 / r * 防御側の戦力倍率 / 攻撃側の戦力倍率
    - 防御側の人口損失割合＝0.1 * 防御側被ダメ率 * r * 攻撃側の戦力倍率の平均 / 防御側の戦力倍率

### 人口損失割合の例
- 1ユニットvs1ユニットで正面突撃
  - もし、攻撃側の人口が防御側の人口と同等の場合、下記となる
    - 攻撃側の人口損失割合＝0.1*防御側の戦力倍率/攻撃側の戦力倍率
    - 防御側の人口損失割合＝0.1/(1+地形防御ボーナス)*攻撃側の戦力倍率/防御側の戦力倍率
    - 地形ボーナスなしの場合
      - 例：戦力倍率10の歩兵で、戦力倍率1の開拓者を攻撃した場合、1ターンで開拓者は消滅し、歩兵は1%だけ損耗する。
      - 例：戦力倍率10の歩兵で、戦力倍率10の歩兵を攻撃した場合、両者とも1ターンで10%ずつ消耗し、(log10(人口)+2)*21.9ターンで双方消滅する。
      - 例：戦力倍率20の歩兵で、戦力倍率10の歩兵を攻撃した場合、1ターン目で攻撃側は5%消耗、防御側は20%消耗する。ターンを追うごとに消耗率は開き、6ターン後に防御側消滅時に攻撃側は16%の損耗に留まる。
  - もし、攻撃側の人口が防御側の人口の1/10の場合、下記となる
    - 攻撃側の人口損失割合＝1.0*防御側の戦力倍率/攻撃側の戦力倍率
    - 防御側の人口損失割合＝0.01/(1+地形防御ボーナス)*攻撃側の戦力倍率/防御側の戦力倍率
    - 地形ボーナスなしの場合
      - 例：戦力倍率10の歩兵で、戦力倍率1の開拓者を攻撃した場合、拮抗して両者とも1ターンで10%ずつ消耗し、(log10(人口)+2)*21.9ターンで攻撃側が消滅する、防御側は0.1残る。
  - もし、攻撃側の人口が防御側の人口の10倍の場合、下記となる
    - 攻撃側の人口損失割合＝0.01*防御側の戦力倍率/攻撃側の戦力倍率
    - 防御側の人口損失割合＝1.0/(1+地形防御ボーナス)*攻撃側の戦力倍率/防御側の戦力倍率
    - 地形ボーナスなしの場合
      - 例：戦力倍率10の歩兵で、戦力倍率10の歩兵を攻撃した場合、1ターンで攻撃側は歩兵を1%損耗し、防御側は100%損耗する
  - もし、攻撃側の人口が防御側の人口の半分の場合、下記となる
    - 地形ボーナスなしの場合
      - 例：戦力倍率20の歩兵で、戦力倍率10の歩兵を攻撃した場合、損失率が拮抗し、(log10(人口)+2)*21.9ターンで攻撃側が消滅する、防御側は0.02残る。

### 包囲攻撃の優位性
- 同じ戦力倍率同士において、敵兵士数と同数である自国歩兵がユニットを1/6づつに分けて囲み突撃したとする。
  - 敵国歩兵が防御陣形でない場合、6面から同時突撃の場合
    - 同時突撃ボーナス・包囲ボーナス・側面攻撃ボーナスが発生し、
      - 自国（攻撃）側の人口損失割合の平均＝0.1(1.0+0.8+0.8+0.2+0.2+0.0)/6=0.05で0.5倍
      - 敵国（防御）側の人口損失割合＝0.1*(1.0+1.2+1.2+1.8+1.8+2.0)=0.9 で9倍 
    - 敵国側歩兵も1/6のユニットのいずれかに突撃する場合、
      - 自国（防御）側の人口損失割合＝0.6が１ユニット（他5ユニットは0）=６ユニット全体の損失割合は0.1
      - 敵国（他国）側の人口損失割合＝0.1/6
      - であり敵国側は1/6しか損耗しない
    - 上記を合計すると、
      - 自国側の総人口損失割合=0.15
      - 敵国側の総人口損失割合=0.9+0.0167=0.92
      - 敵国の方が損失が6.1倍
  - 敵国歩兵が防御陣形の場合、6面から同時突撃の場合
    - 同時突撃ボーナス・包囲ボーナスが発生し、
      - 自国（攻撃）側の人口損失割合の平均＝0.1
      - 敵国（防御）側の人口損失割合＝0.1*6 で6倍 
      - 敵国の方が損失が6倍
- 敵国歩兵と同数である自国歩兵がユニットを1/2づつに分けて前後で挟撃したとする。
  - 敵国歩兵が防御陣形でない場合、2面から同時突撃の場合
    - 同時突撃ボーナス・包囲ボーナス・側面攻撃ボーナス・が発生し、
      - 自国（攻撃）側の人口損失割合の平均＝0.1(1.0+0.0)/2=0.05で半減する
      - 敵国（防御）側の人口損失割合＝0.1*(1.0+2.0)=0.3 で3倍 
    - 敵国側歩兵も1/2のユニットのいずれかに突撃する場合、
      - 自国（防御）側の人口損失割合＝0.2が１ユニット（他1ユニットは0）=2ユニット全体の損失割合は0.1
      - 敵国（他国）側の人口損失割合＝0.1/2
    - 上記を合計すると、
      - 自国側の総人口損失割合=0.15
      - 敵国側の総人口損失割合=0.3+0.05=0.35
      - 敵国の方が損失が2.3倍
  - 敵国歩兵が防御陣形の場合、2面から同時突撃の場合
    - 同時突撃ボーナス・包囲ボーナスが発生し、
      - 自国（攻撃）側の人口損失割合の平均＝0.1
      - 敵国（防御）側の人口損失割合＝0.1*2 で2倍 
      - 敵国の方が損失が2倍
- 敵国歩兵と同数である自国歩兵がユニットを1/2づつに分けて隣り合って攻撃したとする。
  - 敵国歩兵が防御陣形でない場合、2面から同時突撃の場合
    - 同時突撃ボーナス・包囲ボーナス・側面攻撃ボーナスが発生し、
      - 自国（攻撃）側の人口損失割合の平均＝0.1(1.0+0.8)/2=0.09で1割減する
      - 敵国（防御）側の人口損失割合＝0.1*(1.0+1.2)=0.22 
    - 敵国側歩兵も1/2のユニットのいずれかに突撃する場合、
      - 自国（防御）側の人口損失割合＝0.2が１ユニット（他1ユニットは0）=2ユニット全体の損失割合は0.1
      - 敵国（他国）側の人口損失割合＝0.1/2
    - 上記を合計すると、
      - 自国側の総人口損失割合=0.19
      - 敵国側の総人口損失割合=0.27
      - 敵国の方が損失が1.4倍
  - 敵国歩兵が防御陣形の場合、2面から同時突撃の場合
    - 同時突撃ボーナス・包囲ボーナスが発生し、
      - 自国（攻撃）側の人口損失割合の平均＝0.1
      - 敵国（防御）側の人口損失割合＝0.2 
      - 敵国の方が損失が2倍
