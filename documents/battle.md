## 戦闘

### 戦闘可否

- 国同士には交戦状態と平和状態がある
- 交戦状態にある別国のユニット・拠点・施設と同じマスに自国ユニットが入ろうとした場合は戦闘となる場合がある
  - 自国ユニットが軍事ユニットの場合：戦闘となる
  - 自国ユニットが民間ユニットの場合：戦闘とならない
- ただし、交戦状態にある別国のユニットと同じマスに平和状態にあるその他の国のユニットがいる場合、戦闘にならない
- また、交戦状態にある別国のユニットが平和状態にあるその他の国の拠点・施設上にいる場合、戦闘にならない

### 戦闘順序
- 戦闘は次の順序で行う
  - 軍事海上ユニットからの狙撃（に対する防御）
  - 海上ユニットの人口減少による定員オーバー処理
  - 軍事陸上ユニットからの狙撃（に対する防御）
  - 海上ユニットの人口減少による定員オーバー処理
  - 軍事海上ユニットからの突撃（に対する防御）
  - 海上ユニットの人口減少による定員オーバー処理
  - 軍事陸上ユニットからの突撃（に対する防御）
- 定員オーバー処理
  - 乗船中の全陸上ユニットを同じ割合で定員になるまで減損
- 攻撃・防御対象を決定
  - 「移動・突撃」アクションの目標位置に敵ユニットがいる場合、軍事ユニットでは突撃攻撃が発生する。この目標位置は当該ユニットが進入可能な地形である必要がある。ただし、乗船中の陸上ユニットが船と共に海上ユニットに突撃する場合に限り、進入不可な海上地形であってもOKとする。
  - 「狙撃」アクションの目標位置に敵ユニットがいる場合、狙撃攻撃が発生する。）
- 戦闘によってユニットの人口が0.01を下回った場合、取り除く

### 戦闘結果を左右する要素
- 武装値
  - 資源活用によって向上する。
- 地形防御ボーナス
  - 防御側は地形による地形防御ボーナスを得る
    - 平野：0.0
    - 丘陵：0.5
    - 山：1.0
    - 海：0.0
    - 航行可能な河川（陸上ユニット）：-0.5
    - 航行可能な河川（海上ユニット）：0.0
  - 防御側は森林による地形防御ボーナスを得る
    - +森林の値(0~100)/200
  - 防御側は防衛陣地よる地形防御ボーナスを得る
    - 防衛陣地：+0.5
  - 最大ボーナス：山(1.0)+森（0.5）+防衛陣地（0.5）=2.0
- 防御態勢
  - 拠点・施設内にいるユニットで本ターンに攻撃・移動していないユニットに適用される
- 側面攻撃ボーナス
  - 攻撃側は防御態勢でないユニットを正面以外から攻撃している場合、側面攻撃ボーナスを得る
    - 60度：0.2
    - 120度：0.8
    - 180度：1.0
  - 防御態勢のユニットを攻撃している場合、側面攻撃ボーナスは得られない
- 同時突撃ボーナス　※狙撃では発生しない
  - 防御側を同時に突撃しているユニット数(1~12の値)の倍率ボーナス
  - 「陸上ユニットからの攻撃」では最大１２ユニットから同時に突撃されうる。６地点×２ユニットタイプ（騎兵・歩兵）
  - 「海上ユニットからの攻撃」では最大６ユニットから同時に突撃されうる。６地点×１ユニットタイプ（軍船）
- 包囲ボーナス
  - 防御側を同時に攻撃している方向数(1~6の値)の倍率ボーナス
- 城壁強度
  - 防御側が城壁強度が0でない拠点上にいる場合、防御側の人口損失が減り攻撃側の人口損失が増える

### デザイン
- 戦力（人口×戦力倍率）で劣る場合は、守勢（攻撃を仕掛けず防御態勢）が有利になる。時間を少し稼げる（狙撃とどちらがいいか不明？）
- 戦力（人口×戦力倍率）で勝る場合は攻勢（狙撃or突撃）
  - ユニットを攻める場合
      - 人口損失を抑えたい場合は狙撃が有利。ただし時間がかかる。
      - 早期に殲滅したい場合は突撃が有利。ただし人口損失あり。
  - 城壁のない拠点（守備ユニットあり）を攻める場合
    - ユニットを攻める場合と同じ
  - 城壁のある拠点（守備ユニットあり）を攻める場合
    - 火薬を使えるなら狙撃すべき。（人口損失なく城壁を壊せる）
    - 火薬をつかえないなら突撃する（人口損失は大きい）か兵糧攻め。
      - 兵糧攻めは、拠点の周囲の農場を非稼働状態にしたうえで、拠点から２マス離れた位置に軍事ユニットを３～６配置し、輸送隊の進入を妨害する
    - ※現在、拠点の降伏勧告や寝返りの仕組みがないが将来取り入れたい

### スタックの扱い
- 攻撃対象のマスに複数のユニットがいる場合、そのうちのどれか１ユニットのみが攻撃対象となる。軍事ユニット優先・同じユニットタイプを優先し下記の順序となる。
  - 歩兵ユニットの攻撃の場合
    - 歩兵⇒騎兵⇒軍船⇒探検隊⇒物資輸送隊⇒食糧輸送隊⇒労働者⇒開拓者⇒商船
  - 騎兵ユニットの攻撃の場合
    - 騎兵⇒歩兵⇒軍船⇒探検隊⇒物資輸送隊⇒食糧輸送隊⇒労働者⇒開拓者⇒商船
  - 軍船ユニットの攻撃の場合
    - 軍船⇒騎兵⇒歩兵⇒商船⇒探検隊⇒物資輸送隊⇒食糧輸送隊⇒労働者⇒開拓者

### 戦闘の計算
- 戦闘の計算は、「軍事海上ユニットからの狙撃」、「軍事陸上ユニットからの狙撃」、「軍事海上ユニットからの突撃」、「軍事陸上ユニットからの突撃」の４段階でそれぞれ分けて計算する。
  - それぞれの段階で0.01を下回ったユニットは消滅する。最大で４ユニットタイプが１ターンで１マスから消滅しうる。

- 防御側被ダメ率
  - (1+側面攻撃ボーナス) / (1+城壁強度) * 包囲ボーナス / (1+地形防御ボーナス)
- 攻撃側被ダメ率
  - (1-側面攻撃ボーナス) * (1+城壁強度) / 同時突撃ボーナス

- 人口損失
  - 狙撃攻撃の場合
    - 攻撃側の人口損失＝なし
    - 防御側の人口損失＝0.05 * 防御側被ダメ率 * 攻撃側の人口 * 攻撃側の戦力倍率 / 防御側の戦力倍率
  - 突撃攻撃の場合
    - 攻撃側の人口損失＝0.1 * 攻撃側被ダメ率 * 防御側の人口 * 防御側の戦力倍率 / 攻撃側の戦力倍率
    - 防御側の人口損失＝0.1 * 防御側被ダメ率 * Σ(攻撃側の人口* 攻撃側の戦力倍率) / 防御側の戦力倍率 
      - ※Σは全攻撃ユニット
    - つまり下記を意味する
      - 攻撃側の人口が防御側の人口のr倍であるとき、
      - 攻撃側の人口損失割合＝0.1 * (1-側面攻撃ボーナス) * (1+城壁強度) / 同時突撃ボーナス / r * 防御側の戦力倍率 / 攻撃側の戦力倍率
      - 防御側の人口損失割合＝0.1 * (1+側面攻撃ボーナス) / (1+城壁強度) * 包囲ボーナス / (1+地形防御ボーナス) * Σ(r * 攻撃側の戦力倍率 / 防御側の戦力倍率)
        - ※Σは全攻撃ユニット
- 物資損失
  - 狙撃攻撃の場合
    - 攻撃側の物資損失＝攻撃側の人口
    - 防御側の物資損失＝防御側の人口×0.1
  - 突撃攻撃の場合
    - 攻撃側の物資損失＝攻撃側の人口×0.1
    - 防御側の物資損失＝防御側の人口×0.1
- 城壁強度損失
  - 拠点・施設に守備ユニットがいる場合
    - 防御側の城壁強度損失＝Σ(攻撃側の人口 / 拠点人口 * 攻撃側の戦力倍率 / 防御側の戦力倍率)*攻城倍率
      - ※Σは全攻撃ユニット
    - 例：拠点人口の1/10の戦力倍率10の歩兵で戦力倍率10の歩兵がいる拠点を攻撃した場合、1ターンで城壁は0.1減る（10ターンでなくなる）
  - 拠点・施設に守備ユニットがいない場合
    - 防御側の城壁強度損失＝Σ(攻撃側の人口 / 拠点人口 * 攻撃側の戦力倍率)*攻城倍率
      - ※Σは全攻撃ユニット
    - 例：拠点人口の1/10の戦力倍率10の歩兵で攻撃した場合、1ターンで城壁はなくなる
  - 攻城倍率
    - 突撃の場合は1
    - 武装値が2以下の狙撃（=火器なし）の場合は0.1
    - 武装値が3以上の狙撃（=火器）の場合は1

### 人口損失割合の例
- 1ユニットvs1ユニットで正面突撃
  - もし、攻撃側の人口が防御側の人口と同等の場合、下記となる
    - 攻撃側の人口損失割合＝0.1*防御側の戦力倍率/攻撃側の戦力倍率
    - 防御側の人口損失割合＝0.1/(1+地形防御ボーナス)*攻撃側の戦力倍率/防御側の戦力倍率
    - 地形ボーナスなしの場合
      - 例：戦力倍率10の歩兵で、戦力倍率1の開拓者を攻撃した場合、1ターンで開拓者は消滅し、歩兵は1%だけ損耗する。
      - 例：戦力倍率10の歩兵で、戦力倍率10の歩兵を攻撃した場合、両者とも1ターンで10%ずつ消耗し、(log10(人口)+2)*21.9ターンで双方消滅する。
      - 例：戦力倍率20の歩兵で、戦力倍率10の歩兵を攻撃した場合、1ターン目で攻撃側は5%消耗、防御側は20%消耗する。ターンを追うごとに消耗率は開き、6ターン後に防御側消滅時に攻撃側は16%の損耗に留まる。
  - もし、攻撃側の人口が防御側の人口の1/10の場合、下記となる
    - 攻撃側の人口損失割合＝1.0*防御側の戦力倍率/攻撃側の戦力倍率
    - 防御側の人口損失割合＝0.01/(1+地形防御ボーナス)*攻撃側の戦力倍率/防御側の戦力倍率
    - 地形ボーナスなしの場合
      - 例：戦力倍率10の歩兵で、戦力倍率1の開拓者を攻撃した場合、拮抗して両者とも1ターンで10%ずつ消耗し、(log10(人口)+2)*21.9ターンで攻撃側が消滅する、防御側は0.1残る。
  - もし、攻撃側の人口が防御側の人口の10倍の場合、下記となる
    - 攻撃側の人口損失割合＝0.01*防御側の戦力倍率/攻撃側の戦力倍率
    - 防御側の人口損失割合＝1.0/(1+地形防御ボーナス)*攻撃側の戦力倍率/防御側の戦力倍率
    - 地形ボーナスなしの場合
      - 例：戦力倍率10の歩兵で、戦力倍率10の歩兵を攻撃した場合、1ターンで攻撃側は歩兵を1%損耗し、防御側は100%損耗する
  - もし、攻撃側の人口が防御側の人口の半分の場合、下記となる
    - 地形ボーナスなしの場合
      - 例：戦力倍率20の歩兵で、戦力倍率10の歩兵を攻撃した場合、損失率が拮抗し、(log10(人口)+2)*21.9ターンで攻撃側が消滅する、防御側は0.02残る。

### 包囲攻撃の優位性
- 同じ戦力倍率同士において、敵兵士数と同数である自国歩兵がユニットを1/6づつに分けて囲み突撃したとする。
  - 敵国歩兵が防御陣形でない場合、6面から同時突撃の場合
    - 同時突撃ボーナス・包囲ボーナス・側面攻撃ボーナスが発生し、
      - 自国（攻撃）側の人口損失割合の平均＝0.1(1.0+0.8+0.8+0.2+0.2+0.0)/6=0.05で0.5倍
      - 敵国（防御）側の人口損失割合＝0.1*(1.0+1.2+1.2+1.8+1.8+2.0)=0.9 で9倍 
    - 敵国側歩兵も1/6のユニットのいずれかに突撃する場合、
      - 自国（防御）側の人口損失割合＝0.6が１ユニット（他5ユニットは0）=６ユニット全体の損失割合は0.1
      - 敵国（他国）側の人口損失割合＝0.1/6
      - であり敵国側は1/6しか損耗しない
    - 上記を合計すると、
      - 自国側の総人口損失割合=0.15
      - 敵国側の総人口損失割合=0.9+0.0167=0.92
      - 敵国の方が損失が6.1倍
  - 敵国歩兵が防御陣形の場合、6面から同時突撃の場合
    - 同時突撃ボーナス・包囲ボーナスが発生し、
      - 自国（攻撃）側の人口損失割合の平均＝0.1
      - 敵国（防御）側の人口損失割合＝0.1*6 で6倍 
      - 敵国の方が損失が6倍
- 敵国歩兵と同数である自国歩兵がユニットを1/2づつに分けて前後で挟撃したとする。
  - 敵国歩兵が防御陣形でない場合、2面から同時突撃の場合
    - 同時突撃ボーナス・包囲ボーナス・側面攻撃ボーナス・が発生し、
      - 自国（攻撃）側の人口損失割合の平均＝0.1(1.0+0.0)/2=0.05で半減する
      - 敵国（防御）側の人口損失割合＝0.1*(1.0+2.0)=0.3 で3倍 
    - 敵国側歩兵も1/2のユニットのいずれかに突撃する場合、
      - 自国（防御）側の人口損失割合＝0.2が１ユニット（他1ユニットは0）=2ユニット全体の損失割合は0.1
      - 敵国（他国）側の人口損失割合＝0.1/2
    - 上記を合計すると、
      - 自国側の総人口損失割合=0.15
      - 敵国側の総人口損失割合=0.3+0.05=0.35
      - 敵国の方が損失が2.3倍
  - 敵国歩兵が防御陣形の場合、2面から同時突撃の場合
    - 同時突撃ボーナス・包囲ボーナスが発生し、
      - 自国（攻撃）側の人口損失割合の平均＝0.1
      - 敵国（防御）側の人口損失割合＝0.1*2 で2倍 
      - 敵国の方が損失が2倍
- 敵国歩兵と同数である自国歩兵がユニットを1/2づつに分けて隣り合って攻撃したとする。
  - 敵国歩兵が防御陣形でない場合、2面から同時突撃の場合
    - 同時突撃ボーナス・包囲ボーナス・側面攻撃ボーナスが発生し、
      - 自国（攻撃）側の人口損失割合の平均＝0.1(1.0+0.8)/2=0.09で1割減する
      - 敵国（防御）側の人口損失割合＝0.1*(1.0+1.2)=0.22 
    - 敵国側歩兵も1/2のユニットのいずれかに突撃する場合、
      - 自国（防御）側の人口損失割合＝0.2が１ユニット（他1ユニットは0）=2ユニット全体の損失割合は0.1
      - 敵国（他国）側の人口損失割合＝0.1/2
    - 上記を合計すると、
      - 自国側の総人口損失割合=0.19
      - 敵国側の総人口損失割合=0.27
      - 敵国の方が損失が1.4倍
  - 敵国歩兵が防御陣形の場合、2面から同時突撃の場合
    - 同時突撃ボーナス・包囲ボーナスが発生し、
      - 自国（攻撃）側の人口損失割合の平均＝0.1
      - 敵国（防御）側の人口損失割合＝0.2 
      - 敵国の方が損失が2倍
