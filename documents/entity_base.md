# 拠点

## プロパティ
拠点は生成されたときに下記の固定プロパティを持つ
|固定プロパティ|説明|値|
|--|--|--|
|位置|拠点が存在するマップ上の座標|定住アクションを実行したユニットの位置|

拠点はターン経過とともに変わりうる下記の変動プロパティを持つ
|変動プロパティ|説明|初期値|
|--|--|--|
|所属|指揮権を持つ国|定住アクションを実行した所属国|
|接続|この拠点と直接接続している他の拠点のリスト|なし|
|備蓄食糧|拠点が保持している食糧の量|定住アクションを実行したユニットの携行食糧|
|備蓄材料|拠点が保持している材料の量|定住アクションを実行したユニットの携行材料|
|備蓄物資|拠点が保持している物資の量|定住アクションを実行したユニットの携行物資|
|拠点人口|拠点の人口|定住アクションを実行したユニットのユニット人口|
|飢餓ポイント|食糧不足による体力の低下の程度を表す。最低0、最大20。10を超えると拠点人口が減少を始める|定住アクションを実行したユニットの飢餓ポイント|
|忠誠心|各国に対する好感度(-100~100)|所属国に対しmax(100-首都からの距離*(5-技術レベル),0)、他の国に対し0|
|城壁規模|城壁の量を表す。拠点人口が増えた場合に、城壁の効果を維持するには城壁規模も併せて大きくする必要がある|0|
|城壁強度|0より大きい場合、攻撃側の損失を高め、防御側の損失を減ずる|0|
|占領ポイント|占領状態における占領活動の累積値|0|
|最終情報取得ターン|各国ごとにこの拠点の変動プロパティを取得した最後のターン|なし|
|基準人口増加率|食糧が足りているときに人口が増える割合。衛生状況が改善すると増加する|0.05|

拠点は変動プロパティから計算で求まる従属プロパティを持つ
|変動従属プロパティ|説明|計算式|
|--|--|--|
|労働需要|就労人口の最大値|この拠点に接続している労働施設の総数|
|就労人口|この拠点に接続している労働施設で労働している人口|min(労働需要,拠点人口)|
|最大備蓄食糧|拠点で保持できる備蓄食糧の最大値|人口×N。Nの値は200/(平均気温+降水量)。∞>=N>=1。※１|
|素最大城壁強度|素材から得られる城壁の最大防衛力を表す。|1+石材ボーナス(0～3)|
|最大城壁強度|城壁の最大防衛力を表す。城壁規模に対して拠点人口が多すぎる場合強度は低下する。|min(素最大城壁強度,技術レベル+1,城壁規模/拠点人口)で決まる|
|視界|見える範囲|周囲2周(1+6+12=19マス)。人口0の場合は0|
|占領状態|占領されているかどうか|拠点に所属国以外の陸上軍事ユニットがいる場合true|
|忠誠ボーナス|忠誠心による補正割合(-0.2～0.2)|忠誠心/100*0.2。占領中でない場合は所属国への忠誠心、占領中は占領国への忠誠心を用いる|
|収集食糧|拠点がこのターンに収集する食糧の量|接続している施設の獲得食糧の合計|
|収集材料|拠点がこのターンに収集する材料の量|接続している施設の獲得材料の合計|
|収集資金|拠点がこのターンに収集する資金の量|接続している施設の獲得資金の合計|
|収集科学|拠点がこのターンに収集する科学の量|接続している施設の獲得科学の合計|
|人口増加率|食糧が足りているときに人口が増える割合|基準人口増加率+資源ボーナス|


- ※１：平均気温>=降水量が成り立つことを用いると、下記が成り立つ
  - 100/平均気温<=N<=200/平均気温
    - 例えば平均気温25の時、4<=N<=8

## 生成
- ゲーム開始時の初期指定で最初の拠点（首都）が生成される
- ユニットアクション解決フェーズ
  - 拠点作成能力をもつユニットの[定住アクション](phase.md#定住・編入)によって生成される。

- 拠点作成可能地点
  - 拠点作成可能な地形である※森林が20未満に限る
  - 他国の軍事ユニットがいない
  - 既存の拠点から３マス以上離れ

- 資源・特産品の上に拠点を作成した場合、資源・特産品の利用はできなくなる。

## 消失
- 単に人口が0になっただけでは消失しない
- ユニットアクション解決フェーズ
  - [拠点破壊アクション](phase.md#拠点破壊)によって拠点人口が0.01より小さくなった場合消える

## 所属の移転
拠点の所属国の変更は下記で発生する
- 忠誠心が低いことによる「独立」「離反」。詳細は[拠点忠誠変化](phase.md#拠点忠誠変化)参照。
- 占領ポイントが高いことによる「組込」詳細は[占領進行](phase.md#占領進行)参照。
- 交戦状態から平和状態に移行した場合、所属が移転しうる。詳細は[外交](entity_country.md#外交)参照。

## 首都
- 現在の首都が消失もしくは他国に所属が移転した場合、「首都なし」状態となる
  - いずれかの自国拠点が首都移転アクションを行うまで「首都なし」状態は継続する
  - 首都なしの場合、「首都からの距離」は値としてmax(マップの高さ,マップの幅/2)が使用される
  - 首都は占領中であっても、「首都からの距離」は占領されていない時と同様に計算される

## 拠点同士の接続

- 拠点と拠点は、陸路もしくは海路で接続しうる
- 直接接続
  - 他国ユニットによる通行阻害は考慮しない
  - 拠点の支配国が異なる場合
    - 支配国同士が交戦関係にある場合は接続されない
  - 接続は視界にかかわらず成立する
- 陸路での直接接続
  - 拠点圏と拠点圏が、道路もしくは拠点圏に属さない施設によって接続している場合に、拠点が陸路で接続しているものとする
  - 道及び拠点圏に属さない施設は所属によらずどの国も通行可能として扱う
  - このルートは拠点と拠点の間の接続コストが最小になるよう求める（拠点圏と拠点圏の最短ルートではない）。接続コストは移動タイプ「輸送隊」の移動コストで求める。
- 海路での直接接続
  - 港Aと他の港Bの間に移動タイプ「船」で通行可能なルートがあり、そのルート上に他の港がない場合、港Aと港Bは接続しているとみなす。
  - このルートは港と港の間の接続コストが最小になるよう求める。接続コストは移動タイプ「船」の移動コストで求める。
  - 海/湖は施設のあるなしによらずどの国も通行可能として扱う
  - 拠点圏中のマスはその所属国と戦争中の場合通行不能として扱う
- 拠点と拠点の直接接続は最大１。陸路・海路それぞれで接続している場合、よりコストが小さい方のみ接続しているものとする。
- 間接接続
  - 直接接続しているルートを2以上たどった時に拠点同士がつなげられる場合、間接接続と呼ぶ。
  - 例：拠点A-拠点B-拠点C-拠点D
    - 拠点Aの支配国と拠点Dの支配国が交戦状態であったとしても、AB間、BC間、CD間が交戦状態になければ、交易路は有効
- 接続の効果
  - 首都と繋がっている場合
    - 毎ターンの忠誠変化の向上が2倍になる
  - 他の拠点と陸路のみで繋がっている場合
    - 石炭ボーナスが1以上ある場合、ある拠点で食糧・物資・材料を消費するタイミングで不足があっても他の拠点の備蓄から使用できる。道の長さは石炭ボーナス×10マスまで有効。

## アクション
- 占領状態でない拠点毎に下記いずれかの拠点アクションを決定する（何も選択しないことも可能）

|拠点アクション|指定項目|消費|効果|
|--|--|--|--|
|募集|陸上ユニットタイプ/人口（人口上限以下）|ユニットに与えた携行食糧・携行材料・携行物資と同量の備蓄食糧・備蓄材料・備蓄物資。ユニット人口分の拠点人口|拠点上に陸上ユニットを生成|
|放棄|-|全ての備蓄食糧・備蓄材料・備蓄物資。拠点を消滅させる|拠点上に拠点人口に等しい開拓者ユニットを生成|
|造船|水上ユニットタイプ/人口（人口上限以下）|ユニットに与えた携行食糧・携行材料・携行物資と同量の備蓄食糧・備蓄材料・備蓄物資。ユニット人口分の拠点人口|接続している造船所・プラント上に水上ユニットを生成|
|築城|-|城壁規模向上量の備蓄物資|城壁規模を拠点人口*0.1向上（ただし、最大城壁規模を超えない）。最大城壁規模=拠点人口×min(4,技術レベル+1)。城壁強度も城壁規模向上量/拠点人口だけ向上|
|城壁修復|-|城壁強度回復量*拠点人口の備蓄物資|拠点の城壁強度を0.1回復（ただし最大城壁強度を超えない）。|
|祭り|-|資金1|所属国への忠誠心+1|
|首都移転|-|資金5|この拠点が首都になる|
